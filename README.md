# Dompetku - Praktikum PAB Pertemuan 7

Praktikum Pemrograman Aplikasi Bergerak: **ListView, TabBar, Image.asset, Image.network**.

- Nama : Khoirun Nisak
- NIM  : 202432028
- Prodi: S1 Sistem Informasi, Institut Teknologi PLN

## Fitur
- Tab **Transaksi**: `ListView.builder` + total pengeluaran
- Tab **Kategori**: `GridView.builder` 2 kolom (Tugas 3)
- Tab **Statistik**: transaksi dengan nominal terbesar + peringkat (Tugas 2)
- Tab **Profil**: `Image.network` (cover), `AssetImage` (avatar)
- Form tambah transaksi dengan dropdown kategori bergambar
- Kategori baru **Kesehatan** dengan gambar sendiri (Tugas 1)

## Menjalankan
```
flutter pub get
flutter run
```
